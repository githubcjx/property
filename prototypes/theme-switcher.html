主题切换 · 原型

点左侧色卡，整机实时换肤。所有主题共用深色玻璃底，只切换强调色与背景星云色调。

实现机制：

  • 每套主题 = 一组 CSS 变量（--bg / --accent / --liquid …）
  • app.wxss 定义 .theme-xxx 覆盖类
  • 页面根节点加 theme-{{theme}}，变量级联到全部子元素
  • 偏好存 pref_theme，onShow 同步（同 hideAmount 套路）

87 处白色玻璃叠加在深色底上全部继续有效，零回归。
