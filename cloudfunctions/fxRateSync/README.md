# fxRateSync 汇率每日同步云函数

每天 **09:00（北京时间）** 自动抓取一次真实汇率，写入云数据库 `fxRates` 集合，供小程序端读取。全员共用同一份数据，每天只请求一次第三方接口，节省额度。

> 数据源每天 **00:00 UTC（北京 08:00）** 更新一次，我们晚 1 小时（北京 09:00）抓，确保拿到当天已发布的最新值，避开更新瞬间可能抓到旧值的问题。

## 它做什么

1. 从 [open.er-api.com](https://open.er-api.com)（免费、无需 key）取以人民币为基准的最新汇率；
2. 反算成「1 外币 = X 人民币」（与小程序 `utils/currency.js` 的 `rates` 约定一致）；
3. 以日期（`YYYY-MM-DD`，北京时区）为 `_id` 写入 `fxRates` 集合，幂等覆盖当天、保留历史。

## 数据结构（`fxRates` 集合）

```json
{
  "_id": "2026-06-25",
  "date": "2026-06-25",
  "base": "CNY",
  "rates": { "USD": 7.18, "HKD": 0.915, "JPY": 0.0455, "...": 0 },
  "source": "open.er-api.com",
  "fetchedAt": <serverDate>
}
```

> `rates[X]` 含义：**1 单位外币 = X 人民币**。CNY 为锚定币，不入表（恒为 1）。

## 部署

1. `cd cloudfunctions/fxRateSync && npm install`
2. 微信开发者工具 → 云开发 → 右键该函数 → **上传并部署（云端安装依赖）**。
3. 首次可在控制台「测试运行」立即拉一条，确认 `fxRates` 集合生成。
4. 在云开发控制台为 `fxRates` 集合设置**权限：所有用户可读**（汇率是公共数据；仅云函数写）。可选建索引：`date` 降序。

## 定时规则

`config.json` 的 cron 在 **UTC**（北京时间 − 8h）。`0 0 1 * * * *` = 每天 UTC 01:00 = **北京 09:00**。

## 无外部密钥

本函数不需要任何 API key / 环境变量；若将来更换为需要鉴权的汇率源，请用云函数「环境变量」配置密钥，切勿硬编码。
