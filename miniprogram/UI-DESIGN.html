净值本（Property Mini-Program）

类型：微信小程序· 定位：个人净资产快照工具· 版本：V1.1· 主题：深色（黑底）

一、产品概览

「净值本」是一款面向个人的净资产快照工具，定位与传统记账软件不同——它聚焦于「账户余额」维度（建议每月录入一次），自动汇总净资产并展示趋势，不记录每一笔流水。

核心数据模型：

  • 账户（Account）：所属大类 / 子类 / 名称 / 余额（以「分」为单位）/ 是否计入图表 / 备注。
  • 变动记录（Transaction）：每次「修改余额（set）」或「增减金额（delta）」生成一条记录，含金额、变动后余额、备注、时间。
  • 大类（Category）：5 个内置大类——流动资金、投资、固定资产、应收款、负债（负债在净资产计算时取负值）。

技术栈：原生小程序框架（glass-easel）+ 微信云开发（CloudBase）+ ECharts（图表分包，懒加载）。

组件 & 交互

  • 手风琴大类 header 点击切换展开，状态持久化到 Storage（idx_expanded_categories）。
  • 左滑删除账户详情页的变动记录支持左滑显示「删除」按钮（阈值 30px，一次只允许一条打开）。
  • FAB首页右下角悬浮按钮簇（趋势 + 设置）。
  • 底部抽屉金额输入面板（amount-input 组件），含自定义数字键盘。
  • 隐藏金额全局眼睛开关，所有金额变为「¥****」，状态由 app 全局保存。
  • 软删除账户删除是软删除（标记隐藏），历史变动记录保留。

3.1 布局结构（自上而下）

  1. 顶栏 TopBar（自定义、贴顶、状态栏占位）：左侧「我的净资产 + 眼睛切换」，右上角「＋」添加账户。
  2. 净资产数额（大字号，金额已计算 = 资产合计 − 负债，仅 includeInChart=true 的账户参与）。
  3. 大类分组列表（scroll-view 内）：
    • 仅展示有账户的大类；按 5 大类固定顺序：流动资金 / 投资 / 固定资产 / 应收款 / 负债。
    • 每个大类 = category-header 组件 + 可展开的账户列表（手风琴交互）。
    • 大类 header 显示：图标（按色调着色）、大类名、最近更新时间、总金额（按大类色显示）、展开箭头。
    • 账户卡片（account-card）显示：图标、账户名、金额、备注/「不计入图表」、最近更新。
  4. 底部 FAB 簇（右下绝对定位）：
    • 📊 趋势 → 跳转 chart 分包
    • ⚙ 设置 → 跳转 settings
  5. 空态：无账户时，居中显示钱包图标 + 「还没有账户」+ 引导按钮「添加账户」。

3.2 交互细节

  • 眼睛点击：切换金额隐藏（全局态），所有金额变为 ¥****。
  • 大类点击：仅切换展开/收起，不进入大类详情（无大类详情页）。
  • 账户卡片点击：进入账户详情页。
  • 展开状态写入 Storage，下次进入恢复。
  • 分包预加载：进入首页后预加载 chart 分包，让趋势页秒开。

4.1 三步流程

  1. Step 1：选大类——5 个大类竖向列表，点击行展开/收起当前大类的子类（同页内展开，类似手风琴）。
  2. Step 2：选子类——子类显示在大类下方缩进，选择 custom 类型（如「其他」）会弹出 wx.showModal 输入自定义名称。
  3. Step 3：填表单（step=3）——切到表单视图，包含：
    • 账户名称（默认占位：子类名；建议输入中性名）
    • 初始余额（仅新增显示，编辑模式隐藏）
    • 计入图表开关（默认开）
    • 备注（多行 textarea，maxlength=100）
    • 提交按钮（白底黑字大按钮）

4.2 编辑模式

URL 带 editId 时直接进入 Step 3，并通过 loadEdit 拉取账户预填表单，标题改为「编辑账户」，按钮变为「保存修改」。

4.3 子类配置（来自 categories.js）

  • 流动资金：现金 / 支付宝 / 微信 / 银行卡 / 其他
  • 投资：基金 / 股票 / 其他
  • 固定资产：房产 / 汽车 / 其他
  • 应收款：应收款（自定义）
  • 负债：负债（自定义）

5.1 头部信息

  • 大图标（按子类图标渲染）+ 右上角操作（编辑 ✎ / 更多 ⋯）。
  • 账户名（中等字号）。
  • 当前余额（大字号，按大类色显示：负债显示红色，其他显示对应大类色）。

5.2 操作按钮

  • ＋／－ 增减金额（白底黑字主按钮）→ 打开 amount-input 抽屉（mode=delta）。
  • ≡ 修改余额（半透明按钮）→ 打开 amount-input 抽屉（mode=set）。

5.3 变动记录列表

  • 每行：备注（默认按变动类型）/ 时间 / 金额（绿/红：+ 为绿，− 为红） / 变动后余额。
  • 左滑显示删除按钮（120rpx 宽红色按钮）。同一时刻只允许一条展开，已展开时 tap 用于关闭，不会进入详情。
  • 未展开时 tap 行 → 跳转「变动详情」页。
  • 删除变动时使用 wx.showModal 二次确认，账户余额按本次变动金额反向回退。

5.4 更多操作（⋯ 按钮）

调用 wx.showActionSheet 弹出「删除账户」红色项，二次确认后软删除——账户从首页隐藏，历史记录保留。

5.5 编辑按钮（✎）

跳转 add-account?editId=XXX 进入编辑模式。

8.1 布局结构

  1. 文字摘要：时间范围 + 当前 Tab 对应的两个指标变化（起 / 止 / 涨跌额 / 涨跌幅）。
  2. Tab 切换：
    • 净资产 / 负债（双线：白色净资产 + 红色负债，净资产带渐变填充）
    • 流动 / 投资（双线：绿色流动资金 + 紫色投资）
  3. 图表区：基于 ECharts 的 ec-canvas，懒加载初始化。
    • X 轴：时间标签，Y 轴：金额（≥1w 时显示「¥X.Xw」）
    • Tooltip：黑底白字，显示对应日期各条曲线金额。
    • 隐藏金额时 Y 轴和 Tooltip 显示 *** / ****。
  4. 时间范围分段控件（Segmented）：30天 / 6月 / 1年 / 年初至今 / 自定义。
  5. 自定义日期选择器（仅当选「自定义」时显示）：两个 date picker——「起」「止」。

8.2 空态

当无任何账户数据时显示 📈 + 「暂无数据，先在首页添加账户并记录余额」，画布透明化。

8.3 性能优化

  • 分包：避免主包体积；首页 preloadRule 预加载。
  • lazyLoad: true：等 onReady 后再 init，避免阻塞初次渲染。
  • 切 Tab 仅重渲图表，不重拉数据（数据按时间范围拉取后缓存在 _seriesData）。
